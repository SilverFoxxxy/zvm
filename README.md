# ZVM (Zhelezyaka Virtual Machine)

**Железяка**, или **ЖВМ** — Железячная Вычислительная Машина.
Простая виртуальная машина с 16 регистрами и набором инструкций в стиле ассемблера.

## Справочник

```asm
; --- Ввод-вывод ---
READ -> Rx          ; читает число из ввода в Rx
WRITE Rx            ; печатает значение Rx (с пробелом, если строка не пуста)
WRITE NL            ; перевод строки, сбрасывает флаг «уже печатали в строке»

; --- Присваивание ---
MOV X -> Ry          ; Ry = X (X — регистр или число)

; --- Арифметика ---
ADD X, Y -> Rz        ; Rz = X + Y
SUB X, Y -> Rz        ; Rz = X - Y
MUL X, Y -> Rz        ; Rz = X * Y
DIV X, Y -> Rz        ; Rz = X / Y (целочисленное деление)
MOD X, Y -> Rz        ; Rz = X % Y (остаток от деления)
; деление на ноль — ошибка исполнения

; --- Сравнения (результат: 1 = истина, 0 = ложь) ---
EQ X, Y -> Rz         ; Rz = 1, если X == Y
NE X, Y -> Rz         ; Rz = 1, если X != Y
LT X, Y -> Rz         ; Rz = 1, если X < Y
GT X, Y -> Rz         ; Rz = 1, если X > Y
LE X, Y -> Rz         ; Rz = 1, если X <= Y
GE X, Y -> Rz         ; Rz = 1, если X >= Y

; --- Логика (работает с 0/1; любое ненулевое = истина) ---
AND X, Y -> Rz        ; Rz = 1, если оба операнда истинны
OR  X, Y -> Rz        ; Rz = 1, если хотя бы один истинен
XOR X, Y -> Rz        ; Rz = 1, если ровно один истинен
NOT X -> Rz           ; Rz = 1, если X = 0 (иначе 0)

; --- Метки и переходы ---
MARK name             ; ставит метку (точка перехода)
JUMP name             ; безусловный переход к метке
JUMPIF Rx, name       ; переход к метке, если Rx ≠ 0

; Обозначения:
;   X, Y — операнд: регистр (R0..R15) или число
;   Rz — целевой регистр (всегда регистр)
;   NL — специальная константа «перевод строки» (только для WRITE)

```

### Пример

```asm
; Считать два числа, сложить, вывести сумму
READ -> R0
READ -> R1
ADD R0, R1 -> R2
WRITE R2
WRITE NL
```

Подробнее:

```asm
; Считали первое число в R0
READ -> R0

; Считали второе число в R1
READ -> R1

; Сложили R0 и R1, сумму записали в R2
ADD R0, R1 -> R2

; Вывели R2
WRITE R2

; Вывели перевод строки
WRITE NL
```

## Установка и запуск

### Вариант 1

> Linux/macOS, нужны права superuser

Если у вас установлен `git`:

```bash
git clone git@github.com:/SilverFoxxxy/zvm
cd zvm
./install.sh
```

После установки запускайте так:

```bash
zvm hello.zasm
```

### Вариант 2: компиляция вручную (без sudo)

Работает на любой системе.
Понадобится установленный компилятор `g++`.

1. Скачайте файл `zvm.cpp`.
2. Скомпилируйте:

   ```sh
   g++ -std=c++17 -O2 -o zvm zvm.cpp
   ```

3. Запустите из той же папки:

   ```sh
   ./zvm hello.zasm
   ```

## Модель машины

В основе ZVM — три понятия:

- **Программа** — список инструкций. Выполняется последовательно, строка за строкой, начиная с первой. Единственный способ изменить этот порядок — инструкции перехода (`JUMP`, `JUMPIF`).
- **Регистры** — 16 ячеек `R0..R15`, каждая хранит одно целое число. В начале выполнения все регистры равны `0`.
- **ALU** (арифметико-логическое устройство) — выполняет арифметику, логику и сравнения. Берёт операнды из регистров или констант и записывает результат в целевой регистр.

**Инструкция** — одна команда, выполняемая за один шаг. После неё машина переходит к следующей строке (или к указанной метке, если сработала инструкция перехода).

Пример того, как меняются регистры:

```asm
; R0 = 5, R1 = 3 (по умолчанию в начале все 0, это просто иллюстрация состояния)
ADD R0, R1 -> R2    ; R2 = 8
SUB R0, R1 -> R3    ; R3 = 2
MUL R0, R1 -> R4    ; R4 = 15
```

## Синтаксис

- `;` — всё после `;` до конца строки это **комментарий** (машина его игнорирует).
- **Пустая строка** — игнорируется.
- **Регистр** — только `R0`, ..., `R7`, `R15`.
- **Число** — целое: `0`, `42`, `-17`.
- **Стрелка** `->` — Читается как «записать в»:
  Пример: `ADD R1, R2 -> R3` — «сложить R1 и R2, результат записать в R3».
- **Метка** — это просто имя (буквы, цифры, `_`). Она не делает ничего сама по себе: это «табличка», к которой можно перейти.

### Обозначения в описании инструкций

- `X`, `Y` — операнд: регистр или число.
- `Rz` — всегда регистр (целевой, куда записывается результат).
- `NL` — специальная константа («перевод строки»), используется только с `WRITE`.

## Инструкции

### Ввод-вывод

| Инструкция   | Описание                                                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| `READ -> Rx` | Читает одно целое число со входа, записывает в `Rx`.                                                                         |
| `WRITE Rx`   | Печатает число из `Rx`. Если в текущей строке уже что-то напечатано — перед числом ставится пробел.                          |
| `WRITE NL`   | Печатает перевод строки. Сбрасывает счётчик «уже печатали в этой строке», следующий `WRITE` начнёт новую строку без пробела. |

```asm
READ -> R0
READ -> R1
WRITE R0            ; первое число
WRITE R1            ; второе, через пробел
WRITE NL            ; перевод строки
```

### Присваивание

| Инструкция    | Описание                                                 |
| ------------- | -------------------------------------------------------- |
| `MOV X -> Ry` | Записывает в `Ry` значение `X`. `X` — регистр или число. |

```asm
MOV R0 -> R1        ; R1 = R0
MOV 5  -> R2        ; R2 = 5
MOV 0  -> R0        ; обнулить R0
```

### Арифметика

| Инструкция       | Описание                             |
| ---------------- | ------------------------------------ |
| `ADD X, Y -> Rz` | `Rz = X + Y` (сложение)              |
| `SUB X, Y -> Rz` | `Rz = X - Y` (вычитание)             |
| `MUL X, Y -> Rz` | `Rz = X * Y` (умножение)             |
| `DIV X, Y -> Rz` | `Rz = X / Y` (целочисленное деление) |
| `MOD X, Y -> Rz` | `Rz = X % Y` (остаток от деления)    |

Все арифметические инструкции берут два операнда `X` и `Y` (регистры или числа) и записывают результат в `Rz`.

```asm
ADD R1, R2 -> R3    ; R3 = R1 + R2
ADD R1, 1  -> R1    ; R1 = R1 + 1 (инкремент)
SUB 0,  R1 -> R2    ; R2 = -R1
MUL R1, R1 -> R2    ; R2 = R1 * R1 (квадрат)
DIV R1, 10 -> R2    ; R2 = R1 / 10
MOD R1, 10 -> R2    ; R2 = R1 % 10 (последняя цифра)
```

> **Деление на ноль** приводит к ошибке исполнения.

### Сравнения

Каждая инструкция сравнения проверяет условие и записывает в `Rz` результат: `1` (истина) или `0` (ложь).

| Инструкция      | Расшифровка      | Записывает `1`, если… |
| --------------- | ---------------- | --------------------- |
| `EQ X, Y -> Rz` | equal            | `X` равно `Y`         |
| `NE X, Y -> Rz` | not equal        | `X` не равно `Y`      |
| `LT X, Y -> Rz` | less than        | `X` меньше `Y`        |
| `GT X, Y -> Rz` | greater than     | `X` больше `Y`        |
| `LE X, Y -> Rz` | less or equal    | `X` $\le$ `Y`         |
| `GE X, Y -> Rz` | greater or equal | `X` $\ge$ `Y`         |

```asm
EQ R0, R1 -> R2     ; R2 = 1, если R0 равно R1
LT R0, 0  -> R2     ; R2 = 1, если R0 отрицательно
GE R1, R0 -> R2     ; R2 = 1, когда R1 хотя бы R0
```

### Логические операции

Результат сравнения — это **логическое значение**: `0` (ложь) или `1` (истина). Логическое значение — обычное число, но мы договариваемся читать его так: ноль — «нет», единица — «да».

Логические операции комбинируют логические значения. Любое ненулевое число считается истиной, ноль — ложью. Результат — всегда `0` или `1`.

| Инструкция       | Описание                       | Записывает `1`, если…          |
| ---------------- | ------------------------------ | ------------------------------ |
| `AND X, Y -> Rz` | логическое «и»                 | оба операнда истинны (не ноль) |
| `OR  X, Y -> Rz` | логическое «или»               | хотя бы один операнд истинен   |
| `XOR X, Y -> Rz` | исключающее «или»              | ровно один операнд истинен     |
| `NOT X -> Rz`    | логическое «не» (один операнд) | `X` равен нулю                 |

```asm
AND R0, R1 -> R2    ; R2 = 1, если оба не ноль
NOT R0     -> R1    ; R1 = 1, если R0 равен нулю
NOT 5      -> R1   ; R1 = 0 (5 — истина, поэтому «не» — ложь)
```

Сравнения и логические операции можно комбинировать. Например, проверим, что `R0` лежит в отрезке от нуля до ста:

```asm
; проверка: 0 <= R0 <= 100
LE 0,  R0   -> R1    ; R1 = 1, если 0 <= R0
LE R0, 100  -> R2    ; R2 = 1, если R0 <= 100
AND R1, R2  -> R3    ; R3 = 1, если оба условия верны
JUMPIF R3, OK        ; если R3 истина – идём к метке OK
```

### Метки и переходы

| Инструкция        | Описание                                                                                                              |
| ----------------- | --------------------------------------------------------------------------------------------------------------------- |
| `MARK name`       | Ставит метку в текущей строке. Это точка, на которую можно перейти. Удобно для схем: от `JUMP` стрелка идёт к `MARK`. |
| `JUMP name`       | Безусловный переход к метке `name`.                                                                                   |
| `JUMPIF Rx, name` | Переход к метке `name`, если `Rx` не равен нулю.                                                                      |

`MARK name` ставит метку — как табличку с названием. Это не «начало цикла» и не «блок if», просто точка в коде, к которой можно перейти.

```asm
MARK START          ; ставим метку
...
JUMP START          ; возвращаемся к ней
```

`JUMPIF` проверяет, что значение не равно нулю. Ноль — ложь, любое другое число (`1`, `2`, `-1`, `100`) — истина. Поэтому результат сравнения можно сразу передавать в `JUMPIF`:

```asm
EQ R0, 0 -> R1
JUMPIF R1, DONE     ; перейти к DONE, если R0 равен нулю
```

## Примеры

### Проверка на чётность

Вводится число. Если оно чётное — вывести результат деления на два. Если нечётное — вычесть единицу и вывести результат.

**Схема**

![](examples/even-odd.drawio.svg)

**Код**

```asm
; Начало программы
READ -> R1
MOD R1, 2 -> R2
EQ R2, 0 -> R3
JUMPIF R3, EVEN
JUMP ODD

; Блок обработки для чётного
MARK EVEN
DIV R1, 2 -> R4
WRITE R4
WRITE NL
JUMP END

; Блок обработки для нечётного
MARK ODD
SUB R1, 1 -> R4
WRITE R4
WRITE NL
JUMP END

; Конец программы
MARK END
```

### Квадраты

Вводится число — выводим его квадрат. Повторяем, пока не введут ноль.

**Схема**

![](examples/squares.drawio.svg)

**Код**

```asm
MARK START
READ -> R1
    ; Если ввели ноль – завершим программу
    EQ R1, 0 -> R3
    JUMPIF R3, END
MUL R1, R1 -> R2
WRITE R2
WRITE NL
JUMP START

MARK END
```
